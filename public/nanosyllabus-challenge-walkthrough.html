✕

› The idea: Software execution is a tradeoff between pre-translating source code for performance and delaying translation for runtime flexibility.

This topic covers how high-level code is prepared for a computer to process — compilation versus interpretation, and the structured path from human-readable code to machine instructions.

1. Compiled versus Interpreted Execution

Think of a compiled language like a pre-translated book: the work is done once before you pick it up. An interpreted language is a translator sitting next to you, sentence by sentence.

Why this step: it decides whether a program favours raw speed or the ability to change and debug on the fly.

In the exam: name the execution model, give one advantage of each, and draw the translate → run pipeline.
